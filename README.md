# Aussie EcoLens

Aussie EcoLens is a FIT5225 Assignment 2 multi-cloud serverless wildlife media platform. Authenticated users can upload wildlife images and videos, the system classifies the media with MegaDetector + SpeciesNet, stores searchable metadata, and notifies users when newly processed media matches their subscribed tags.
